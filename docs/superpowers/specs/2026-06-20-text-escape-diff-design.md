# 文本转义输入输出差异对比设计

## 目标

在文本转义转换工具现有输入输出编辑框中自动显示差异，不增加独立对比面板，也不改变转换、复制、映射配置和快捷键行为。

## 交互

- 输入区中被移除或变化的字符使用浅红背景。
- 输出区中新增或变化的字符使用浅绿背景。
- 中间操作区显示移除和新增字符数。
- 转换、交换、清空以及手动修改输入输出时自动刷新。
- 输入输出为空时隐藏差异层和统计。

## 实现

在现有行号栏旁增加高亮层，textarea 在有对比结果时透明显示文字并保留光标和选择效果。高亮层、textarea 和行号栏同步垂直滚动，高亮层额外同步水平滚动。

差异计算使用公共前后缀缩减和字符级最长公共子序列；中间区域乘积超过 1,000,000 时退化为整段删除和新增，避免长日志导致内存或计算时间异常。

## 验证

- 自动测试覆盖差异分段、DOM 结构、滚动同步和版本号。
- 浏览器验证转义转换后的红绿高亮、行号以及控制台错误。
