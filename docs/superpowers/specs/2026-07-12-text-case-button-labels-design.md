# 命名转换按钮文案优化

## 目标

让用户无需试用即可区分两个下划线命名转换按钮。

## 文案

- `constant` 转换按钮由“常量变量名”改为“大写下划线命名”，输出示例：`userName` -> `USER_NAME`。
- `snake` 转换按钮由“下划线命名”改为“小写下划线命名”，输出示例：`userName` -> `user_name`。

不调整转换逻辑、按钮位置、布局或其他功能文案。

## 验证

- 页面显示两项新文案，不再显示两项旧文案。
- `constant` 和 `snake` 按钮仍分别调用原有转换类型。
- 命名转换相关测试及完整测试集通过。
