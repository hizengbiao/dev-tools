# URL 编解码差异对比设计

## 目标

在 `url-encoder.html` 中增加编码或解码后的自动差异对比，并提供交换输入输出功能。

## 交互

- 输入和输出编辑框采用左右双栏布局。
- 用户点击编码或解码后，直接在原输入框和输出框内显示字符级差异。
- 输入框中删除内容用红色标记，输出框中新增内容用绿色标记。
- 输入输出完全相同时显示“输入输出内容一致”。
- 点击“交换输入输出”后，两侧内容互换，并立即刷新差异。
- 清空操作同时清空差异展示。

## 实现

- 页面内新增纯函数 `buildDiffSegments`，使用最长公共子序列计算字符级差异片段。
- 页面内新增 `renderDiff`，通过与原生文本框叠加的高亮层安全渲染差异，不拼接用户输入 HTML。
- 高亮层与文本框滚动位置同步；移动端自动切换为上下布局。
- 保持现有单文件、无第三方依赖的实现方式。

## 验证

- 自动测试覆盖相同文本、新增、删除、替换及交换输入输出。
- 页面结构测试覆盖差异区域和交换按钮。
