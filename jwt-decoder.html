JWT 解析工具

V1.02 ℹ️
本工具仅本地解析 JWT 的 Header 和 Payload，用于查看内容和时间字段；不验证签名可信性，也不会判断令牌是否真的来自可信签发方。

JWT 输入

等待输入 JWT。

Header

解析后显示 Header JSON。

Payload

解析后显示 Payload JSON。

时间字段

解析后会展示 exp、iat、nbf、auth_time 等时间字段。

签名片段

解析后显示签名片段；这里不验证签名可信性。
