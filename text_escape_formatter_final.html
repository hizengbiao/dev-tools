变量映射配置

每组填写两个需要互相替换的值，左右顺序不影响结果。同一配置既用于合并拼接字符串，也用于恢复变量拼接； 转换时会用当前输入中命中的一侧替换为另一侧。配置会自动保存在当前浏览器。

示例：SERVICE_NAME ↔ SVNM.getName() 已配置 0 组
说明： “字符串模式”用于指定 Java、JavaScript、Python、SQL 等不同字面量规则；“转为可读文本”适合把一行转义字符串展开为正常多行内容； “转为转义字符串”适合把多行文本转换成可直接复制到 Java、JSON、配置文件或日志字段里的字符串；“多行转代码字符串”适合把普通多行文本转换成 Java 风格的字符串拼接代码； “清理堆栈日志”适合去除日志前缀、统一 Java 堆栈缩进并清理多余空行； “合并拼接字符串”可结合变量映射把代码中的字符串和指定变量合并成普通文本； “恢复变量拼接”可将普通文本中的映射内容重新转换成变量表达式拼接，未配置的变量仍会保留边界。 快捷键：Ctrl + Enter 转为可读文本，Ctrl + Shift + Enter 转为转义字符串。
