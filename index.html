一系列实用的开发小工具

📑

JSON 格式化工具

格式化、压缩、修复 JSON。支持语法高亮、折叠展开、按键排序等功能。

 ⏱️

时间戳转换

Unix 时间戳与日期互转。支持秒/毫秒单位切换，多种时区选择。

 🔗

URL 编解码

URL 编码与解码工具。可以对 URL 进行 Encode 和 Decode。

 🔐

Base64 编解码

Base64 字符串与文件转换。支持 UTF-8 文本和文件 Base64 编码。

 🔎

哈希/摘要工具

计算文本和文件的 MD5、SHA-1、SHA-256、SHA-512 摘要，支持复制单项结果和摘要比对。

 🎫

JWT 解析工具

本地解析 JWT Header 和 Payload，展示 exp、iat、nbf 等时间字段，并明确不做签名可信校验。

 🎲

UUID / 随机值生成器

生成 UUID v4、随机字符串、随机数字和密码，支持配置数量、长度、字符集并批量复制。

 🔤

文本命名转换

大小写、蛇峰、驼峰、短横线等常见命名格式互转，适合变量名和文案快速整理。

 🧾

文本转义转换工具

转义字符串与可读多行文本互转，适合日志堆栈、JSON 字符串、配置字段等内容快速处理。

 ✂️

文本智能拆分

按指定长度将长文本拆分为多段，优先在换行、标点和单词空格处断开，并支持逐段快速复制。

 🔎

正则表达式测试

在线测试正则匹配与替换，支持常用标志位、匹配列表、分组详情和高亮预览。

 ⏲️

Neon Timer (React)

赛博朋克风格的计时器与倒计时。支持全屏、动态背景与大数字显示。
