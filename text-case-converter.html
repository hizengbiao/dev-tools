命名格式转换

选择目标命名格式或文本处理方式，结果会输出到右侧区域。支持每行一个变量名批量转换。

支持从普通短语、下划线、短横线、点号、斜杠和驼峰变量名中拆词，再转换为常见代码命名格式。“清理多余空格”会去掉每行首尾空白，并把连续空格压缩为单个空格。字段提取可从简单 SQL select 字段、Java 字段声明和 JSON key 中提取名称。“生成代码命名”会输出常量、枚举、Getter 和 Setter。
