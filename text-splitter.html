2026年7月22日
V1.10
将每段最大长度的默认值由 2950 调整为 2900。
2026年7月15日
V1.09
新增脱敏与反脱敏功能：支持配置双向文本映射、浏览器自动保存及 JSON 配置导入导出；开始拆分前可自动脱敏，反脱敏结果可在右侧直接查看和复制。
2026年7月13日
V1.08
移除 Token/字符长度模式选择，默认按字符长度拆分；移除分段前缀、后缀及模板复制和模板校验选项。
2026年7月11日
V1.07
新增分段合并校验，自动检查拆分结果按顺序合并后是否与原文一致，并在失败时提示首个差异位置。
V1.06
新增拆分策略选择，支持智能边界、按行、按段落、按句子和硬字符拆分，超长单元会自动兜底拆分。
V1.05
新增分段前缀/后缀模板，支持 {index}、{total} 变量，并可选择复制时是否包含模板。
V1.04
新增 Token 估算拆分模式，可在字符长度和 token 估算之间切换，并在结果中显示每段字符数和估算 token 数。
2026年6月20日
V1.03
新增逐段加入剪切板历史功能，按顺序保存各分段，方便通过 Win + V 逐段选择粘贴。
V1.02
优化大量文本粘贴体验，避免页面自动滚动到底部；拆分结果调整为六行高度并支持滚动和全屏查看。
V1.01
为输入文本和每段拆分结果增加行号，并移除结果区嵌套的纵向滚动条。
V1.00
版本初始化：支持按指定长度智能拆分文本，优先保留自然语义边界，并支持逐段快速复制。
